Privacy policy

saglik is a personal app used only by its owner. This policy covers the data it accesses through Google APIs.

Data accessed

With the owner's permission, saglik reads the owner's own data from the Google Health API using read-only scopes: activity and fitness, health metrics and measurements, sleep, nutrition, location of recorded exercises, and basic profile information.

How the data is used

The data is used only to show the owner their own health statistics and trends. It is not used for advertising, profiling, or any other purpose.

Storage and sharing

The data is stored only on the owner's own device. It is not sold, shared with, or transferred to any third party. saglik never writes to or changes data in the owner's Google account.

Google API Services User Data Policy

saglik's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from Google Account › Third-party connections. Deleting the app's data folder on the device removes all stored data.

Contact

Questions can be sent to the support email shown on the app's Google sign-in consent screen.
